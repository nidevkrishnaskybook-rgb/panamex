1. EXECUTIVE SUMMARY

Panamex Inhouse Management System is a web-based operational control platform for container movement, demurrage/free-time tracking, port formalities, yard operations, alerts and management reporting.

The platform is designed to reduce manual tracking, eliminate costly port and shipping line demurrage penalties, improve deadline visibility and provide a centralized operational view for management and operational staff.

Configurable Intake Engine Pronto BI Excel/CSV dual-table import, shipping line and port rule configurations.

8. KEY COMMERCIAL NOTES
  • Total Fixed Commercials: The one-time turnkey implementation fee is fixed at ₹ 1,15,000 (Indian Rupees).
  • Enterprise Security Included: Multi-tier RBAC authentication, WAF/Anti-DDoS, automated backups, and detailed change-history audit trails are covered under security hardening.
  • Annual Hosting Renewal: Annual hosting renewal is applicable directly to the selected cloud hosting provider (Hostinger, AWS Lightsail, or Render).
  • Provider Flexibility: Cloud hosting provider and deployment region can be chosen or adjusted before final production deployment.
  • Exclusions: Taxes, payment gateway charges, third-party subscriptions and usage-based external APIs are excluded unless specifically included.
  • Custom Additions: Major feature additions, workflow changes or external ERP integrations outside the agreed scope can be estimated separately.
  • Backend Stack Choice: If Python/Django is selected for production instead of PHP/Laravel, an additional development charge will apply.
9. FINAL DEMO SUMMARY

Current demo: The working demonstration uses HTML, CSS, JavaScript, JSON and Node.js/server.js to present the operational workflows and interactive interface.

Next stage: The production system is proposed to be developed using PHP, Laravel and MySQL for a structured backend, relational database and persistent operational data.

Alternative: Python with Django and MySQL is also possible. This alternative requires an additional development charge because it involves a different backend implementation and technology stack.
